# Contributing to Manageur

Thanks for contributing. Manageur stores user-maintained service inventory on disk, so fixtures and screenshots must use fictional services and never include personal data or credentials.

## Before opening a pull request

1. Use macOS 14 or later with Swift 5.9 or later.
2. Run `swift test` and `swift build -c release`.
3. Add or update tests for model, storage, or audit-engine changes.
4. Document any changes to the local JSON format or privacy behavior.

Report vulnerabilities through [SECURITY.md](SECURITY.md), not a public issue.
